## Датасет вкратце

`data/synthetic.csv` содержит 1005 строк (1000 после дедупликации), одна строка =
один синтетический клиент с тремя признаками: `age`, `income`, `spend`. Периода нет —
данные cross-sectional. Качество в целом **приемлемое для демо-стенда пайплайна, но
не для продуктовых выводов**: переменные независимы, есть отрицательные денежные
значения и расхождение README с файлом по числу пропусков.

## Топ проблем качества

### Проблема 1: Переменные независимы — сигнала нет
- **Что:** `income`↔`spend` r = −0.054, `age`↔`spend` r = −0.020 (все |r| ≤ 0.054 при пороге 0.5).
- **Влияние:** датасет не поддерживает ни одной зависимости; любой «инсайт» на нём фиктивен.
- **Действие:** либо связать признаки в генераторе (`spend = f(income)` + шум), либо подключить реальные данные.
- **Владелец:** аналитик / владелец проекта.

### Проблема 2: Отрицательные денежные значения (validity FAIL)
- **Что:** `spend < 0` в 6 строках, `income < 0` в 1 строке; `spend_rate < 0` в 7 строках (min −7.62).
- **Влияние:** искажает mean/sum и делает `spend_rate` бессмысленным; причина — `np.random.normal` без обрезки.
- **Действие:** `np.clip(..., 0, None)` или логнормальное распределение в `generate_synthetic_data`.
- **Владелец:** дата-инженер / автор генератора.

### Проблема 3: Ярлык «Pareto» завышает концентрацию
- **Что:** `segmentation_report.md`: top-20% дают 31.5% трат — это всего 1.58× базовой линии 20%; Gini = 0.24.
- **Влияние:** правило 80/20 не выполнено, но отчёт подаёт число как «Pareto».
- **Действие:** переименовать метрику или добавить Gini/Lorenz рядом.
- **Владелец:** аналитик.

### Проблема 4: README: 20 пропусков против 21 в файле
- **Что:** README (строка 36) — «20 пропусков в `income`»; в `data/synthetic.csv` их 21.
- **Влияние:** ломает инвариант «правда» портфолио; мелочь, но проверяемая.
- **Действие:** поправить README на 21 или генерировать пропуски после конкатенации дубликатов.
- **Владелец:** автор проекта.

### Проблема 5 (низкий приоритет): разрыв по когортам — артефакт малой выборки
- **Что:** max/min среднего `spend` по `age_group` = 1.07, но когорта `66+` имеет всего n=83.
- **Влияние:** минимальный; ложных выводов не порождает, но показывает хрупкость срезов.
- **Действие:** не трактовать как эффект; при необходимости — bootstrap-CI.
- **Владелец:** аналитик.
